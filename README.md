# File-Based Student Record System

## Description
A Java-based Student Record System using file handling.

## Features
- Add student records
- View all student records
- Search student by ID
- Update student records
- Store data permanently in a file

## Technologies Used
- Java
- File I/O
- BufferedReader
- BufferedWriter
- Scanner

## How to Run

1. Open the project in Eclipse.
2. Run `StudentRecordSystem.java`.
3. Select an option from the menu.
4. Student records are stored in `students.txt`.

## Operations

1. Add Student
2. View Students
3. Search Student
4. Update Student
5. Exit
